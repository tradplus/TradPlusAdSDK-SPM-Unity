# TradPlus Unity Ads Adapter Swift Package

Swift Package Manager support for the TradPlus Unity Ads adapter (15.16.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-Unity.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-Unity.git", exact: "15.16.0")
```

Third-party dependency: Unity Ads `4.20.1`. Minimum iOS 13.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.16.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
